# Modules

Per-package summaries — what each package owns and its public interface.

---

## `server.go`

Application entry point and HTTP server setup.

- Loads config, creates `resources.Tools`, initializes the gqlgen handler.
- Wires the middleware chain: CORS → rate limit → request ID → request context → JWT extraction → logging.
- Registers the `@auth` directive enforcer.
- Serves on `APP_GODUTCH_SERVERPORT` (default 8080).

---

## `graphql/schema/`

GraphQL schema definitions (`.graphqls` files). These are the source of truth for the API contract.

- `endpoint.graphqls` — query and mutation definitions.
- `types.graphqls` — type definitions (User, Group, Expense, Share, etc.).
- `scalar.graphqls` — custom scalars (Decimal, Time).
- `directives.graphqls` — `@auth` directive definition.
- `inputs.graphqls` — input types for mutations.
- `subscription.graphqls` — subscription type for real-time expense updates.

**Do not add resolver logic here.** Schema changes require `make gqlgen`.

---

## `graphql/generated.go`

Auto-generated by `gqlgen`. **Do not edit manually.** Contains all GraphQL plumbing: field resolvers, type resolvers, directive enforcement, subscription handlers.

---

## `graphql/model/`

Auto-generated model types (from `gqlgen.yml`). Also contains the manually maintained `decimal.go` with the custom `Decimal` type mapping to `shopspring/decimal`.

---

## `graphql/resolver.go`

Defines the `Resolver` struct (the composition root for GraphQL resolvers). Embeds `resources.Tools`, holds `*db.Queries`, and `*exchangerate.Service`.

---

## `graphql/*.resolvers.go`

Resolver implementations, split by schema file:
- `endpoint.resolvers.go` — query and mutation resolvers.
- `types.resolvers.go` — field resolvers for computed fields (e.g., `Group.members`, `Expense.payers`).
- `subscription.resolvers.go` — real-time subscription resolver.

---

## `sqlc/query.sql`

SQL queries used for code generation. **This is the source of truth for database queries.** Edit here, then run `make sqlc`.

---

## `sqlc/db/`

Auto-generated type-safe Go code from `sqlc`. **Do not edit manually.** Contains:
- `db.go` — `Queries` struct and `DBTX` interface.
- `models.go` — Go structs for each table.
- `query.sql.go` — type-safe query functions.

---

## `tools/config/`

Environment variable loading using `envconfig`.

**Key type:** `Config` struct with all `APP_GODUTCH_*` fields. Loaded via `config.Load()`.

---

## `tools/resources/`

Dependency injection and wiring.

**Key type:** `Tools` struct containing `Logger`, `Postgres`, `JWT`, `Crypto`, `ExchangeRateKey`. Created via `resources.CreateTools(cfg, ctx)`.

---

## `tools/postgres/`

PostgreSQL connection pool wrapper using `pgx/v5`.

**Key interface:** `IPostgres` — `Pool() *pgxpool.Pool`.

---

## `tools/crypto/`

Password hashing and verification.

**Key interface:** `ICrypto` — `Hash(password string) (string, error)`, `Verify(hash, password string) bool`.

---

## `tools/zerologger/`

Structured logging setup using zerolog.

**Key interface:** `ILogger` — wraps zerolog with request-context propagation.

---

## `tools/pghelper/`

Database utility functions for common patterns (e.g., nullable field helpers, transaction helpers).

---

## `tools/randstr/`

Random string generation for invite tokens and similar use cases.

---

## `tools/exchangerate/`

Exchange rate service. `GetOrRefresh(ctx)` returns a `Result` (rates map, unsupported currencies, fetchedAt). Fast path: returns the cached snapshot if < 24 h old. Slow path: acquires a PostgreSQL advisory lock (session-pinned connection), double-checks, then fetches `exchangerate-api.com/v6/{key}/latest/USD`. Falls back to a stale snapshot on API failure; errors only if no snapshot exists at all. `UnsupportedCurrencies` is computed by diffing DB currencies against the API rate keys.

---

## `migrations/`

Database migration files in `golang-migrate` format.

- `000001_init_table.up.sql` / `.down.sql` — initial schema.
- `000002_seed_currencies.up.sql` — currency seed data.
- `000003_reorder_currencies.up.sql` — currency ordering fix.
- `000004_add_conversions.up.sql` — adds `exchange_rate_snapshots` and `conversions` tables.

Applied automatically by the `migrate` Docker Compose service on startup.
